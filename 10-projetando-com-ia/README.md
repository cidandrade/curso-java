# Projetando com IA

O que faz a diferença quando quem escreve o código é uma IA: testes como especificação executável, princípios SOLID, modelagem de domínio, injeção de dependência e os recursos do Java moderno que a IA usa. Cada aula traz o pedido, o código e a revisão.

| Nº | Aula | Tema |
|---|---|---|
| 063 | [Testes com JUnit](063-testes-com-junit) | Testes automatizados como especificação |
| 064 | [SOLID na prática](064-solid-na-pratica) | Os cinco princípios SOLID: antes e depois |
| 065 | [Modelagem de domínio](065-modelagem-de-dominio) | Do enunciado ao diagrama e às classes |
| 066 | [Injeção de dependência](066-injecao-de-dependencia) | Injeção de dependência e interfaces, sem framework |
| 067 | [Java moderno](067-java-moderno) | Records, sealed, pattern matching, switch como expressão e text blocks |
| 068 | [Projeto integrador](068-projeto-integrador) | Ciclo completo com IA: especificar, pedir, revisar, testar |
