# 012 — Decisão e repetição

**Tema:** Estruturas de decisão e de repetição

## Objetivo

Apresentar as estruturas de controle de fluxo do Java.

## Conceitos-chave

- `if` / `else if` / `else`
- Operador ternário
- `switch` com casos agrupados e `default`
- `while`, `do-while`, `for` e `for (;;)` com `break`
- *for-each* sobre vetor
- `continue`

## Classes principais

| Classe | Papel |
|---|---|
| `EstruturasApp` | Aplicação com todos os exemplos |

## Como executar

Na raiz do repositório:

```bash
mvn -q install -DskipTests      # uma única vez: compila tudo e instala a biblioteca da aula 008
mvn -q -pl 02-recursos-da-linguagem/012-decisao-e-repeticao exec:java
```

Classe principal: `br.com.cidandrade.aulas.EstruturasApp`. Na IDE, basta executar essa classe.

Os resultados aparecem em caixas de diálogo (`JOptionPane`), por isso é preciso ambiente gráfico. Os laços mostram uma caixa por número, então há várias dezenas de caixas para fechar.
