# 006 — Vetores

**Tema:** Vetores (arrays)

## Objetivo

Declarar, criar e acessar vetores unidimensionais e bidimensionais.

## Conceitos-chave

- Declaração e criação com `new int[10]`
- Inicialização com `{ ... }`
- Índices começando em 0
- Matriz irregular (`String[][]` com linhas de tamanhos diferentes)
- `Arrays.toString`

## Classes principais

| Classe | Papel |
|---|---|
| `VetorApp` | Aplicação com todos os exemplos |

## Como executar

Na raiz do repositório:

```bash
mvn -q install -DskipTests      # uma única vez: compila tudo e instala a biblioteca da aula 008
mvn -q -pl 01-fundamentos/006-vetores exec:java
```

Classe principal: `br.com.cidandrade.aulas.VetorApp`. Na IDE, basta executar essa classe.
